📝 Key Exam Facts

Bubble sort compares adjacent elements and swaps them if they are out of order. After each pass, the largest unsorted value “bubbles” to its correct position at the end of the array. Bubble sort uses nested loops — the outer loop controls the number of passes, and the inner loop controls comparisons within each pass. The maximum number of passes needed is n − 1 where n is the number of elements.
