📝 Key Pseudocode Patterns

Bubble Sort (ascending): Uses nested FOR loops. Outer loop = passes, inner loop = comparisons. Comparison: IF array[j] > array[j+1]. Swap uses a temp variable.

Insertion Sort: Outer FOR loop starts at index 1. Stores currentValue. Inner WHILE loop shifts elements right. Uses AND (not OR) in the WHILE condition.

Descending sort: Simply change > to < in the comparison.
