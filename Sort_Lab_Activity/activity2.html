📝 Key Exam Facts

Insertion sort builds a sorted sublist by taking each element from the unsorted section and inserting it into its correct position. It is efficient for processing partially sorted lists as it requires fewer comparisons when elements are already close to their correct positions. Insertion sort divides the array into a sorted sublist and an unsorted section. The sorted sublist starts with 1 element — the first element is always considered sorted.
