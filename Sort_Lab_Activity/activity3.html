📝 Key Exam Points

  • Bubble sort compares adjacent elements and swaps if out of order
  • After each pass, the largest unsorted value “bubbles” to its correct position
  • Insertion sort divides the array into a sorted sublist and an unsorted section
  • Insertion sort is efficient for processing partially sorted lists
  • Both sorts use nested loops and have the same time complexity
  • A temp variable is needed for swapping in bubble sort
