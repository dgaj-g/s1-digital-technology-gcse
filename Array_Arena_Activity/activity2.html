📚 Key Revision Points

  • Accumulator pattern: set total = 0 BEFORE the loop, add inside
  • Finding highest: set highest = array[0], loop from 1, compare with >
  • Counting matches: set count = 0, use IF inside loop, count = count + 1
  • Always use FOR i = 0 TO (size-1) to iterate through an array
  • The loop variable i acts as the index into the array
