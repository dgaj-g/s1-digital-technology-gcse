📚 Key Revision Points

  • Arrays are zero-indexed — the first element is at index 0
  • The last valid index is always (length - 1)
  • Accessing an index outside the array causes an index out of bounds error
  • When iterating through an array, the loop counter acts as the index
  • Expressions like arr[2] + arr[4] evaluate by looking up each value first, then performing the operation
  • Arrays can store integers, strings, reals — but all elements must be the same data type
