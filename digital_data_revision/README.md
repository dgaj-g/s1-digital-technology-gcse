# Digital Data Revision — GCSE Digital Technology Unit 1

Interactive revision activities covering the **Digital Data** topic from CCEA GCSE Digital Technology Unit 1.

## Activities

| # | Activity | Topic | Time |
|---|----------|-------|------|
| 1 | Data Detective | Data vs Information, Storage Units, Conversions | ~10 min |
| 2 | Type Caster | Data Types (Integer, Real, Character, String, Date/Time) | ~8 min |
| 3 | Pixel Lab | Pixels, RGB Colour, Resolution | ~10 min |
| 4 | Graphics Showdown | Bitmap vs Vector, Buffering & Streaming | ~10 min |
| 5 | Sound Studio | ADC, Sample Rate, Bit Depth, Bit Rate | ~10 min |
| 6 | Format Passport Control | Data Portability, File Formats, Compression | ~12 min |

## Deployment

These files are designed to be hosted via GitHub Pages. Upload the `digital_data_revision` folder to your repository and access via:

```
https://<username>.github.io/<repo>/digital_data_revision/
```

## Technical Details

- Pure vanilla HTML/CSS/JavaScript — no dependencies
- Each activity is a single self-contained HTML file
- Works offline — no internet required after loading
- Mobile responsive
