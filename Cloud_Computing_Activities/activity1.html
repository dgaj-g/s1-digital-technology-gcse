Cloud Computing — Key Revision Points

Advantages
Cost effective software delivery, automatic updates, unlimited storage, backup & recovery (provider's responsibility), access from anywhere with internet, reduced carbon footprint.
Disadvantages
Bandwidth limitations and extra charges, potential downtime if internet/router fails, security risks from hackers targeting online data.
Gaming Impact
Developers: reduced distribution costs, global customer base, 24/7 sales, reduced piracy. Customers: immediate downloads, no expensive hardware needed, cloud saves.
File Storage
High-capacity cloud servers store large files. Automatic saving every few seconds. Files stored permanently online. Provider handles crash recovery.
File Sharing
Collaborate from anywhere with internet. Upload and share files instantly. Synchronisation keeps all versions up to date. Example: Google Docs.
