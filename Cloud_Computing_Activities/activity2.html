Key Terms Revision

Cloud Computing
Using the internet to access software, services and data storage on remote servers rather than local hard drives.
Bandwidth
The amount of data that can be transmitted over a network in a fixed amount of time, measured in bits per second.
Synchronisation
When a user changes a cloud file, the change appears in versions used by all other users.
Streaming
Viewing video or playing games via the internet without downloading the full file first.
Scalable Storage
Cloud storage that can be expanded without purchasing additional local hardware.
