# Cloud Computing - Interactive Activities

CCEA GCSE Digital Technology - Cloud Computing topic.

## Overview

This activity set follows the same style as the existing interactive folders and is built from three source sets in the `Cloud Computing` folder:

- `Cloud Computing.pptx`
- `Cloud_Computing_Textbook_Notes.docx`
- `cloud computing PPQ Teacher.docx` (including extracted past-paper question/mark-scheme images)

## Activities

1. `activity1.html` - **Cloud Ops Control**
   - Scenario sorting game across organisation, gaming, and file collaboration contexts.
   - Uses textbook and slide content with mark-scheme-style feedback.

2. `activity2.html` - **PPQ Mark Scheme Sprint**
   - Past-paper style stems with exact point selection and mark allocation.
   - Uses phrasing and accepted points from 2025, 2023, 2019, and 2018 question sets.

## How To Use

1. Open `index.html` in a browser.
2. Click an activity card.
3. Everything runs offline (no server needed).

## Notes

- Pure HTML/CSS/JavaScript (no dependencies).
- Mobile responsive.
- Single-file activity pages for easy sharing/upload.
